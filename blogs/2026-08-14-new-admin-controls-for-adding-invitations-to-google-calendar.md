Google Calendar users have three options for how event invitations are added to their calendar: auto-add invitations from everyone, auto-add invitations from known senders only, or add invitations only after the user responds in email. To date, administrators can only choose the default value for users in their organization. With this release, we’re expanding Calendar settings in the Admin console to offer organizations more granular controls on invitations.
