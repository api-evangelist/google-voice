Google Workspace administrators can now access comprehensive audit logs for Gemini Notebook in the Admin console, providing greater insights into how the application is used across their organizations. This update introduces full visibility into Gemini Notebook actions, allowing administrators to review usage and audit data access in the security investigation tool and audit and investigation tool. Gemini Notebook log events in the ‘Audit and Investigation’ tool in the Admin console.
