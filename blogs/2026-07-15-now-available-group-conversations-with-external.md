For many teams, it’s essential to be able to work in real-time with partners from outside your organization. We’re improving external collaboration in Google Chat by making it possible to create group conversations that include external users. Previously, teams using Google Chat could only create 1:1 conversations with external users, or create a space in Chat with external access enabled.
