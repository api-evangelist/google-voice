We are introducing several new feature enhancements to Google Workspace Studio as part of the October 2026 feature release. These additions expand automation capabilities across Gmail, Google Meet, Google Drive, and custom control logic, giving users more flexibility to build sophisticated workflows without writing code. Specifically, this release includes: Nested Conditionals: Enables nested branching logic within flows so users can build multi-layered conditional decision paths.
