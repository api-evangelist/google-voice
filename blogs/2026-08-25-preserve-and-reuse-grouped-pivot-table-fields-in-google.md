Google Sheets now supports grouped field persistence for pivot tables. When you create custom groupings or work with grouped date, time, or numeric fields, these fields are now retained directly in the pivot table editor sidebar as reusable source fields. This allows you to unassign grouped fields from your active table layout without losing their underlying configuration, making it easy to re-add or modify them at any time.
